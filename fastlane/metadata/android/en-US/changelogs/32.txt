HOTFIX: fixes the v1.0.30 startup crash ("the app installs fine but never opens again"). v1.0.31 makes every launch crash-safe and self-diagnosing: the app now catches its own crashes from the very first process step (a new Application-level guard) and - when a crash report is newer than the last successful open - shows a "Startup problem detected" screen BEFORE the main UI with three actions: Copy report (the full stack trace, ready to paste), Reset app data (erases projects/tasks/tokens/runtime, keeps the report, reopens fresh), and Continue anyway. A crash loop escalates to a full-screen gate. Startup itself was hardened: the Z.ai engine's coroutines and the boot sequence can no longer kill the process on a throw, the task-queue reconcile and project cleanup moved off the main thread (an ANR at launch reads as "the app never opens" on some phones), one malformed saved project no longer erases the whole project list, and token-vault decrypt failures stay non-fatal. Regression tests now load real v1.0.27/28/29/30-era saved payloads into the current loaders and assert no exception + sane defaults. Also: subtle motion polish on the Z.ai live card (breathing phase dot, animated Thinking chevron, model-picker skeletons, haptics) that respects the system "remove animations" setting. If v1.0.30 crashed for you: install this build over it - the crash report from the failed launches appears immediately with a Copy button; send that report so the exact root cause can be confirmed.
