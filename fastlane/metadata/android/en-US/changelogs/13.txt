Updates that could not install before now tell you exactly why and what to do: if your phone still runs a version signed with one of the old signing keys, the update screen says to back up your API key, uninstall once, and install the new APK - no more silent "App not installed" and no more dead-end update errors. The failed-install toast also translates Android's raw failure codes (different signing key, version downgrade) into plain instructions.

One uninstall, once, was forced by history: releases v1.0.4 through v1.0.7 each shipped a different signing key, and Android never lets an app switch keys in place. From v1.0.8 onward every release uses the same key, this release included - so after you are on this version, every future update installs directly over the old one with a single tap, no uninstall, ever.
