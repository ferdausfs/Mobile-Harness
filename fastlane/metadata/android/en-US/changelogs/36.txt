v1.0.35 fixes the crash that could close the app when you expanded "Thinking" or a file diff inside a project chat (a scrolling section measured against unlimited height - every expandable section is now bounded and scroll-safe, and a build-time guard test fails on that pattern forever), and it fixes the file-sync failures seen on the phone. "no chat id in URL": the app now captures the Z.ai conversation id the moment it appears (live-verified: the site moves the URL to /c/<id> about two seconds after you send), keeps one conversation per project, stores the id on the phone, and every sync targets the stored conversation - the current URL no longer matters. "the reply could not be read": instead of reading the page exactly once, the app retries with backoff for about 30 seconds after the site finishes and records a redacted diagnostic (which selectors matched, stop-button state, reply length) shown on the honesty card, so failures are diagnosable instead of blind. Duplicate "Thinking..." lines are gone - one live thinking block, with the site's echoed label stripped. File sources follow your order: the reply's FILE: blocks first, the site's own sandbox data for the stored conversation second, visible code blocks third. The sync card shows the EXACT reason when nothing could be read, and a new "Paste reply" button lets you paste Z.ai's reply text and import its files through the same safety pipeline (relative paths only, size caps, conflict choices, undo). Z.ai projects keep the same Chat / Files / Terminal / Preview tabs as Antigravity, verified by tests. Nothing new runs at startup; installs over v1.0.34 keeping all data.
